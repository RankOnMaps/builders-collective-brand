02 · How to use this document
for whoever's rebuilding it.
This document is a handover from Rank On Maps to whoever rebuilds the deck in Canva. Read it once, then build from it. You should never need to ask "what colour?" or "what font here?" while building. If you do, this doc has failed and we'll fix it.
Who's reading this
  • A Canva designer (Fiverr / Upwork / your own contractor) executing a one-time rebuild. Estimated time: 3 to 4 hours.
  • The Builders Collective team using the resulting Canva file to personalise per client. They never touch the master template, just duplicate and edit specific fields.
What you need before you start
  • Canva Pro plan (required for custom brand fonts, brand kit, and high-quality PDF export with embedded fonts).
  • The reference HTML file: first-appointment-pack.html — open in Chrome to see the final visual target.
  • 4 Google Fonts to upload (listed on the next page).
  • ~3 hours of focused build time. Don't multitask. The mono spacing is finicky.
How to use the page-by-page specs
For each of the 13 deck pages, this document gives you: a thumbnail showing the layout, the exact dimensions of every element, the font + size + color for every text block, and the copy itself. Match it to the reference HTML for cross-check. The reference HTML is the source of truth if anything in this doc is ambiguous.
The bar
"a Canva designer who's never met us should be able to rebuild the whole deck from this doc alone, in one sitting, without asking a single question."

Setup steps in Canva
  1. Go to Canva → Brand → Brand Kits → Create new → name it "Builders Collective".
  2. Download all 4 font families from the Google Fonts links above. Get the full family ZIP (not just one weight).
  3. In your Brand Kit, click Brand Fonts → Upload a font → upload each family. Set roles: Inter Tight = Heading, Fraunces = Subheading, Inter = Body.
  4. Click Brand Colors → add the 4 hex codes above with their names (Forest Floor, Paper, Stone, Fresh Cut).
  5. Go to Logos → for now skip this. We type the wordmark live with brand fonts so it stays editable.

04 · Document settings & recurring elements
five reusable parts.
Every deck page is built from the same five pieces. Set them up once as elements you can copy/paste across pages.
Document settings
  • Page size: A4 portrait, 210 × 297 mm (or custom 1240 × 1754 px at 150dpi).
  • Default margin: 80 px outside on all interior pages. 56 px on cover and contact pages.
  • 13 pages total in one Canva document. Order matters, set up cover (page 01) and contact (page 13) first so the deck reads as a complete pack.
The five recurring elements
01 · The Apex (roof / triangle mark)
Canva element: Triangle shape · Color: Fresh Cut #E8FB94
Aspect ratio: 2:1 (twice as wide as tall)
Sizes: Small 32×16, Medium 56×28, Large 96×48, XL 160×80
The signature mark of the brand. Use Canva's built-in equilateral triangle, scale to the right aspect ratio. Appears at top-left of most pages (small to medium) and as the hero element on the cover (XL).

06 · Variable fields · what changes per client
12 fields the team edits.
Once the Canva template is built, your team duplicates it per new client and changes these specific fields. Nothing else should ever be touched. This list is the single source of truth for "what's editable" — print it, stick it on the wall.

01 Cover {{client_name}} Add client name to top meta strip (optional). If skipping, leave as "First Appointment Pack". First Appointment Pack · 2026 · Perth WA
03 Scenarios {{scenario_active}} Move the chartreuse fill to the buyer scenario tile that matches this client. Other 3 tiles return to default (cream / forest / outline). Tile 02 (Escape rent trap) is highlighted
04 Finance {{fhog_amount}} Update FHOG amount if WA grant changes. Check annually with WA Treasury. $10K
07 3 Steps {{active_step}} Highlight whichever of Finance / Land / Build is the client's current stage. Move chartreuse fill + bottom stage tag. Step 01 Finance is active

10 H&L {{cost_land}} Fill in real land cost during meeting. $xxx,xxx (placeholder)
10 H&L {{cost_siteworks}} Fill in siteworks cost. $xxx,xxx (placeholder)
10 H&L {{cost_house}} {{cost_variations}} {{cost_ppa}} {{cost_total}} Fill in house, variations, PPA fee, total. All 5 lines + total. $xxx,xxx (placeholders)
11 Shortlist {{stamp_saving}} Update savings stamp with the actual wholesale saving on this client's build. $36,300 saving (Byford · 4 BED)
11 Shortlist {{stamp_suburb_brief}} Update stamp footer with suburb + bedroom count. Byford · 4 BED

Don't touch
  • Brand colors. Ever. If you "tweak" green to chartreuse, the whole system breaks.
  • Font sizes or weights. Pick a brand font from the kit, not Canva's defaults.
  • Page order. The pack reads cover → welcome → scenarios → ... → contact. Reordering breaks the narrative.
  • The apex triangle proportion. Always 2:1 (twice as wide as tall). Stretching it sideways looks bad immediately.
  • Stock photos. The brand has zero photography. If you add a stock photo, you've broken the system.

07 · Per-client edit workflow & export
how your team uses it.
Once the master template is built, this is the standard operating procedure your team follows for every new client appointment.
Per-client workflow (10 minutes per client)
For every new client appointment
  1. Duplicate the master. In Canva, open "Builders Collective · First Appointment Pack · MASTER", click the three-dot menu, "Make a copy". Rename to client surname + date, e.g. Smith · 2026-05-21.
  2. Open the variable fields list (previous page of this spec). Print it or pin it next to your screen.
  3. Edit only those fields. Don't touch anything else. If a field doesn't apply to this client (e.g. you don't know their cost numbers yet), leave the placeholder.
  4. Page 03: match the scenario tile to the client's situation by moving the chartreuse fill.
  5. Page 07: set the active step (Finance / Land / Build) based on where the client is.
  6. Page 11: if you've already prepared the shortlist, update the table with the four builder quotes. If not, leave placeholders and tell the client this is what the page will look like at appointment two.
  7. Page 13: swap in the assigned broker's contact details if it's a single-broker assignment.
  8. Quality check: click through all 13 pages in Canva's preview. Look for placeholder $xxx,xxx still visible (means you missed a field). Check spelling.
  9. Export. Top right → Share → Download → File type PDF Print → Quality Print → Check "Crop marks and bleed" only if printing physically → Download.
  10. Send. Email to client with subject line "Your Shortlist of Perth Builders · [Client Surname]".
Quarterly maintenance
  • Page 09 Suburbs: refresh REIWA median prices each quarter (Mar / Jun / Sep / Dec). Update the date stamp at the bottom.
  • Page 04 Finance: verify FHOG amount and low-deposit programs are still current (WA Treasury announcements).
  • Page 06 Stats: revisit "60+ suburbs" / "40+ years" / "100s of designs" annually — bump up if your panel has grown.
Export settings for client-ready PDFs
  • File type: PDF Print (not PDF Standard — Print embeds fonts and outputs at higher resolution).
  • Color profile: CMYK if printing physically, RGB if emailing digitally.
  • Crop marks: only for physical print runs.
  • Flatten: off (keeps text searchable in the PDF).
  • Filename convention: BC-Appointment-[Surname]-YYYYMMDD.pdf, e.g. BC-Appointment-Smith-20260521.pdf.
The whole point
"every client walks out with a pack that names their suburb, their builders, their savings number. it's not a brochure. it's their shortlist."
That's the brand promise. If the deck doesn't say their suburb, their numbers, their builders by name, your team hasn't done their job. The template makes that easy. Now the system has to enforce it.
